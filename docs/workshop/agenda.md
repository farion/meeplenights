# Meeple Night workshop agenda

This is a one-day workshop for experienced developers using Claude Code. All repository artifacts and agent prompts are English.

| Block | Topic | Output |
| --- | --- | --- |
| 09:00 | Explore | Shared map of the existing application |
| 09:20 | Story-Driven Delivery | Interview, stories, and a fully implemented feature; OpenSpec repeat as a stretch goal |
| 13:15 | Backpressure: quality gate | Claude Code quality gate; path-scoped gates as a stretch goal |
| 14:00 | Multi-agent handoff | Implemented readiness change with visible handoffs |
| 14:40 | Rubrics and advisory feedback | Actionable review findings |
| 15:10 | Agent-alignment eval | Evidence of incompatible agent context and review churn |
| 16:00 | Loop intelligence | Measured proposal for improving the agent harness |

Breaks and lunch are intentionally not shown.

## Facilitator setup

1. Confirm Python 3.11+ and Node.js 20+ are available.
2. Participants clone the repository and follow the root README.
3. Do not pre-implement the smart-plan endpoint.
4. Give teams the product decisions only during the `grill-me` exercise, not before.
